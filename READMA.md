 I am going to do the task management project.

**Description:**
A simple task manager where users can create, edit, delete, and organize their daily tasks. Users can mark tasks as done/not done and filter them.
**Features Planned:**
- Add new task (with title, description)
- Edit task
- Delete task
- Mark as Done / Not Done
- Filter tasks (All / Done / Not Done)
- User Authentication (optional)
- Responsive UI

**Tech Stack:**
- Frontend: React + Redux Toolkit
- Backend: Node.js + Express
- Database: MongoDB
- Styling: CSS / Tailwind

**Repository Structure Plan:**
/client - React frontend
/server - Express backend
